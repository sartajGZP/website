One better design / code I propose for a better social media is as follows
.
(1) each user makes shared folders in googledrive / onedrive which is visible to whole public or visible to a few contacts
.
(2) then using app or otherwise, user can put files in his shared folders
.
(3) and using app or otherwise, he can read files from others' public
.
(4) later, instead of shared onedrive or shared googledrive, the data created by user will be on his mobile or his PC or a proxy server he chooses . And data will be written using app and read using aap
.
So now a copy of all data user has written is always with him in a local backup folder. If googledrive ends his account, he can immidiately start a new drive and all links used by others will work !!! The reader can keep a copy or may not.
.
And later, when apps communicate from mobile to mobile, there is no server in-between, or just some proxy.
.
