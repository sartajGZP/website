Creating/Managing UNITS from FB APP
.
It is possible to create group , unit and posts in units using FB app
.
But in order to create FIRST unit in a group, you need CHROME APP . Put ChromeApp in DESKTOP mode (google on how) and then go to group settings . And click on add units. (see google for exact screen layouts)
.
Once first unit is created, you can create any number of units and any number of posts inside a unit
.
To change the order of Units, you need to open Group in ChromeApp after setting ChromeApp in Desktop mode
