Trivially easy way to rig old non-VVPAT EVMs
.
Based on rigorous testing and approximate date in real time clock inside EVM, the EVM code can figure out that poll is only 7 to 10 days away
.
So at that time, EVM can deliberately show wrong time
.
So technician will pull out a clock fixing unit and connect to EVM
.
The clock fixing unit can be rigged to send exact polling datetime and candidate number to be preferred.
.
Now there will be hardly 3-5 clock fixing units per Loksabha. And once the phase of one loksabha ends, these units will be shipped to Loksabha where next phase starts. So totally, only 300 to 500 clock fixing units are needed
.
These units can get polling datetime and candidate number thru radio signals.
.
So in this scheme, EVM does NOT any hardware changes. The code inside it can be rigged at manufacturing time. And code will behave honestly ttill candidate number and datetime comes. And when datetime and candidate number comes, then till actual polling datetime, it will behave honestly, And only on polling date, after mock poll, after 10 am, after 50 votes, it will change votes
.
So in non-VVPAT EVM, vote changing is trivially easy with clock setting unit
