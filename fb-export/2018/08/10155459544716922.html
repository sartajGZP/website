Claims that X is "citizen-verifiable or nagrik pramanit" --- pls ask for the PROCEDURE to be used to VERIFY and see whether this procedure makes OTHER methods equally verifiable or not !!
.
And then check how right or wrong is the claim maker.
.
(Non activists may skip -- the post is about technical issue activists face)
.
----
.
(1) say X says to Y "I have written postcard to PM to print #MRCM7 law-draft given at http://newindia.in//causes/MRCM7 , with my voterid and name. Is it citizen verifiable?
.
Ans: Y can ask X to write postcard again. Since postcards have voterid, the PMO can de-duplicate it. So there is nothing immoral in writing postcard again. So X refuses, Y can assume that X didnt write postcard to begin with. And if X does write postcard again, then Y can now assume that X did indeed write such postcard.
.
(2) say X goes to a website where he a list of 1000 voters with their voter-ids, names, addresses etc but no phone numbers is put by the website-owner. And website-owner claims that all these 1000 voters have asked PM to print #MRCM7 given at http://newindia.in//causes/MRCM7. Is this claim of website-owner citizen verifiable?
.
Ans : The answer is --- WHAT IS THE PROCEDURE FOR VERIFICATION ? Say the phone numbers are NOT shown on website,
.
There can be several procedures.
.
Now one procedure proposed for verification is --- Y can to write letters to N voters, where N = all 1000 voters or say 50 voters chosen at random, And based on replies, Y can decide.
.
But what if NONE of these N reply? And what is only 5% of N reply saying YES or NO? IOW, a list where voter has OPTION of not replying can result in large number of NO REPLIES and make verifiability very very weak.
.
---------
.
Honesty of claim makers :
.
Now using above method of writing letters, many other things are also CITIZEN VERIFIABLE !! eg Say activist X gives a list to Y and list has 1000 voters with voterid/ addresses and Y claims that all 1000 have sent POSTCARDS to PM asking for MRCM7. Then Y can use same method as given in (2) and "verify". !!
.
So now what if a claim maker says "sending SMS to MP or a particular ph# is verifiable, but sending postcard to PM isnt verifiable" !! Well, his claim is now WRONG, Because whatever method one uses to verify whether voters in a given list did indeed send SMS or not, can also be used for to verify postcard sending.
.
So all in all, when claims that "data-1 is citizen verifiable and data-2 is NOT citizen verifiable" pls ask for PROCEDURE CODE that activist has to use for verification of the data. And then see if procedure code has same or different accuracy for data-1 and data-2. And then decide whether claim is right or wrong.
.
-----
.
And if Y has to write letters, then here is a mischief X can use. There are over 50000 closed bungalows/flats in Ahmedabad alone, where owner has moved to USA or mumbai etc and doesnt want to sell away the flat. By an exhaustive survey, X can make a list of 10000 such empty flats / bungalows. And X can show voters of these EMPTY flats as supporters of X's proposals !! So if Y sends 50 to 500 letters for verification, Y will get all NO REPLIES in all these cases !! And postman will simply drop the letter and wont return to Y unless letter is registered post, in which case Y will get it back with note "flat closed".
.
Another issue can be --- Y can be a person Delhi who will write letter in English or Hindi. Then X can make list of voters in rural area of some state, where voters know ONLY local language. So again, almost all letters sent by Y will result in no replies.
.
IOW, where NO REPLY is an option, many foul tricks can be played. The NO REPLY can be genuine no reply, or receiver not not present and many such possibility.
.
-----------------
.
So all in all, when claims that "data-1 is citizen verifiable and data-2 is NOT citizen verifiable" pls ask for PROCEDURE CODE that activist has to use for verification of the data. And then see if procedure code has same or different accuracy for data-1 and data-2. And then decide whether claim is right or wrong.
