Solution to FB blocking groups and fake profiles?
.
Imo, the solution is to have BLOCKCHAIN based social network, which has NO central server. All post remain on public ledgers forever unless a post is deleted by all those who had made copies or those who have made copies are not on net. But a hash of that post will remain.
.
BitCoin uses same Blockchain concept.
.
After party registration work is done, I will see if I can find time to make Blockchain based social network. Meanwhile, other software fluent recallists may try to work on it.
.
Some enhancements I will make to Blockchain are

(1) Use length based encoding and NOT escape character based encoding --- XML uses "/" as escape character for encoding. In my proposed way to encode, length is stated in the beginning to indicate where the character string ends.
.
(2) Encoding using human readable characters only and not using any character that humans cant read to encode Blockchains and public ledgers. IOW, not using binary characters but using only text characters. This may increase storage size by 3 to 4 times, but no more.
,
Based on above Blockchains, imo, one can have social media free from Govt control and also any central authorities control.
.
This can be also used to remove fake users. How? One can create list of verified users and chains of verifications. So one can easily ignore fake profiles.
