(Q3) How to get loksabha constituency name / NUMBER?

Ans : In India, within each State, each Loksabha Constitiency has a SERIAL number. If you are a political party member, then you should know that serial number. eg. serial number of Ahmedabad(West) loksabha constituency where I live is #8.
