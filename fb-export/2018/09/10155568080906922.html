How websites displaying voter-ids will come to end -- new law requires all websites to support "takedown"
.
Pls google on "Right to be forgotten":. This law i yet to be passed in India, but courts have already started giving judgments along this line
.
As per this "right", even if a user has given WRITTEN consent to put his own personal data on a website, the website has to take it down when user requests deletion. Even if written agreement said that website will never remove the data, such condition / agreement are void.
.
This doesnt hold for govt websites. But does hold for private websites
.
Once user asks the website to delete his data, the website has to immidiately hide it. The website can re-show if user asks saying that deletion was done by hacker etc. But if no request to re-show data comes, the website can keep data ONLY to be shown to courts/police etc . The website cannot use that data for display or even any internal analysis.
.
So if a user has uploaded his voter-id and opinions on the website, and then user wants his name, address, voter-id, opinions etc deleted forever, the website has to comply
.
Pls google more on "right to be forgotten".
.
So if website owner refuses to delete, then user can sue and he will win.
.
I will NEVER ask any activist to sue activist on such petty issues. But if website gets data from 1000s of users,a few will cetrainly demand deletion someday. And if deletion is allowed, then opinion list can be seen as tempered. So such website loses the purpose anyway
