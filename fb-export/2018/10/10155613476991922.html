Here is a comparison

(1) data consumed --- In broadcastlist, I am not sure of following --- "Say you have a BROADCAST-LIST (not a GROUP, but broadcast list) which has 100 members and say you send 10 MB video to all Then will data consumed be 10 MB or 1000 MB?".

IOW, broadcastlist can create serious problem if data consumed is 1000 MB, So pls confirm this first

(2) control on conversation --- in group, if one member writes, all members will get message and will get disturbed. now whatsapp has NEW feature that admin can change setting to "only admin can write". But then, some members may feel bad that they are not allowed to write and so may leave. In
.
(3) members' see other members' phno and use for spamming ---- if you make broadcastlist with 100 members, none can see others' phno. But of you make a group of 100 members, then each can see other 99's phno and that can be misused for spamming. IOW, even if settings are so that only admin can write messages, the member can see other members phno, note them down and send messages to them. This can be particularly irritating when some male group users start sending messages to females in the group. So if you are running WA group to distribute video etc, then pls keep males in a separate group as a precaution
.

WhatsApp non-broadcast group now has feature that only administrators can send messages to all members, and non-admin members cannot send messages. I think this feature came in July only.
.
So to publicize info on RTR, you can setup non-broadcast groups with settings that only you can send messages. The minus point is that all members will be able to see names and phone number of all other members too.
.
The plus point is --- you can MONITOR WhatsApp activity of a junior !! How ? Say a senior wants to ensure that junior is indeed sending some message/video to some specific say 300 voters in his WhatsApp group. Then senior can ask junior to setup a VOTER-GROUP with those 300 voters and also add the senior in that group. That way, senior can see that the junior indeed sent the message to all those 300 voters !!
