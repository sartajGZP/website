Dear recallists,
.
The "activism method of order your MP via sms\twitter" is IMO going all wrong. People are sending sms without hashes and sometimes sms dont even have a link !!! Such sms are nothing but e-naarebaazi and e-dharana !! And they are as wasteful as naarebaazi and dharana.

Here I have given instructions for activists, voters and MPs
.
And IMO, without these instructions, AMOYMVST is as useless as naarebaazi.
.
========
.
(1) Instruction for activists
.
(1.1) The activist first MUST put the DRAFT of the proposal in a text file or PDF. If you dont have time to out the proposal in a text or PDF file, then pls dont bother with this "order your MP via sms\twitter" campaign. If an activist doesnt know how to make text or pdf file, then he must get help from technical assistant who knows how to do so.
.
(1.1.a) The file name should be (three to six letter code + dot + 4 digit number + dot + proposal code + dot + txt/pdf). Each activist should give himself a 3 to 6 letter code. eg code I have given to myself is PLD. The activist must ensure that that code is not taken by any other well known activist he knows. This is necessary to avoid clashes in filenames. The number is the proposal number he has given, And proposal code is code he has given to that specific proposal, It should be below 20 characters, eg PLD.0007.TcpIndia.txt is file name of my proposal which has TcpIndia law-draft.
.
(1.1.b) if the proposal is translation, then the translation must have original draft in the file, and also have sha1hash and bittorrenthash of the original file. sha1hash and bittorrenthash are explained later. It must not have link to the files. In fact, no proposal should have links to any private website. The proposals may have links to govt websites or may mention newspaper advertisements / news.
.
(1.1.c) so please note --- the activist MUST MUST MUST put his proposal in a txt of pdf file first before asking anyone to send sms.
.
(1.2) The next step should be to obtain sha1hash of the file. I will refer it as SHA1HASH.
.
(1.3) After putting the proposal in file, the activist SHOULD upload the file in bittorrent. For now, I wont mind if one skips this step. But after an activist has give 2-3 proposals, this step is MUST. And from bittorrent, he must obtain BitTorrentInfoHash . I will refer this hash as BITTORRENTHASH.
.
(1.4) The activist must upload file on a facebook group. Why group? Because in FB, user profiles and pages dont support files for now. So if any FB user wants to upload file, then he can upload the file only in a group. And why FB? because if file is uploaded on uploaded on FB and later the user changes it, then FB will allow him to upload new revision, but not allow him to delete old revision, And FB allows him to delete the file. But then, the readers will know that he has deleted the file. If the website is any other website like say rahulmehta dot com, then I can change the file anyday, and still keep the link same, and also delete old file copy. So FB is better than other less known website,
.
(1.4.a) When the activist uploads the file, he MUST put three things in description -- filename, sha1hash, bittorrenthash.
.
(1.4.b) when a file is uploaded in a FB group, FB gives user an FB status on the group wall, which has description. I will refer to link to this status as FILELINK,
.
(1.5) Then activist MUST put a status on his wall or wall of a group or wall of a page, and that status should have (a) proposal code (b) filename (c) sha1hash (d) bittorrenthash (e) filelink (f) sms to be sent to PM\MP (g) tweet to be sent to PM\MP (h) text of the law-draft (i) request to reader to like/share/copy the status
.
(1.5.a) when above status is created on FB, the FB will give a link which I refer as MAINLINK
.
(1.5.b) why should the status be on FB? Because if many website allow user to edit the post and dont even mention that status has been edited !! FB at least informs the user that status has been edited. So IMO, FB is less bad than most other websites I know,
.
(1.6) The sms \ tweet MUST have sha1hash or bittorrenthash or both. Please note --- sms without hash is 100% pure waste of time. And the sms can also have mainlink, but one of the two hash is MUST MUST MUST. sms without hash is useless.
.
(1.6.a) if proposal is translation of the proposal, then it must have sha1hash or bittorrenthash of original proposal
